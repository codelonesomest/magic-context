# v0.33.0-omp.2

OMP compatibility patch for task subagent historian classification on OMP 17.2.9+.

## Fixes

- Detect OMP task child session IDs when the session JSONL file starts with OMP's fixed-width title slot record before the `session` header.
- Restores `omp.subagents.compaction` classification for lifecycle-attested task children so historian compaction marks OMP task subagents correctly before their first model turn.

## Verification

- `bun test packages/pi-plugin/src/omp-subagent-compaction.test.ts` — 3/3 tests passed, including the OMP fixed-width title-slot session fixture.
