# v0.32.1-omp.3

A focused OMP status migration fix on top of official Magic Context v0.32.1.

## Fixed duplicate `mc:` lines

The first `v0.32.1-omp.3` attempt still allowed two OMP surfaces to coexist: a retained plain `setStatus()` line and the newer themed widget.

Magic Context now keeps OMP on one surface only. On OMP session start it clears any retained `magic-context` widget, then renders the persistent `mc:` line through the plain `setStatus()` footer surface. Session shutdown clears both the footer status and any retained widget. Native Pi behavior remains unchanged.

This trades the experimental OMP themed widget for correctness: exactly one live Magic Context status line, without modifying OMP source, OMP settings, or files under `~/.omp`.

Upstream base: [`cortexkit/magic-context@v0.32.1`](https://github.com/cortexkit/magic-context/releases/tag/v0.32.1)
