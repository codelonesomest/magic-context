# v0.32.1-omp.2

An OMP presentation release on top of official Magic Context v0.32.1.

## Theme-aware Magic Context status

OMP 17 sanitizes ANSI styling from extension `setStatus()` text even though its extension API documents theme-styled statuses. Magic Context now uses an OMP-only, above-editor one-line widget so its persistent context status can follow the active OMP theme without modifying OMP itself.

- `mc:` uses the active theme's bold accent.
- Token usage uses normal theme text.
- Context pressure is success below 50%, warning from 50–79%, and error at 80% or higher.
- The separator uses the muted theme color.
- `idle` is dim, active `historian`/`recomp` states are warning-colored, and recent historian failures are error-colored.
- The widget retains one blank row above and adds one blank row below, separating it from both preceding OMP output and the editor border.
- Long status text is width-aware and truncates safely.
- The widget is removed on session shutdown.

Native Pi keeps the existing plain `setStatus()` integration. OpenCode is unaffected. No OMP source, OMP settings, or files under `~/.omp` are modified by this release.

Upstream base: [`cortexkit/magic-context@v0.32.1`](https://github.com/cortexkit/magic-context/releases/tag/v0.32.1)
